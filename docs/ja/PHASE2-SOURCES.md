# フェーズ2 資料選定案（2026-11-17）

日本語の資料を、英語の資料パックと同じ形の「追加パック（add-on）」として配る前提で選んだ。追加パックは本家の仕組み
（`derived/packs/pack-spec.json` の `addons`、`packaging/pack_merge.py`）に乗るので、英語パックには手を入れない。

選ぶ基準は4つ。

1. **配ってよいか**：ファイルのまま再配布でき、文字の抽出やスクリプト除去などの加工も許されている
2. **信頼できるか**：国・自治体・定評ある団体の資料
3. **実際に役立つか**：住民向けの手順書を優先し、行政向けの計画書は後回しにする
4. **オフラインで読めるか**：PDF・HTML・ZIM のいずれか

規約は、元のページを直接読んで確かめた（2026-11-17）。「要確認」は、まだ一次の確認が取れていないもの。

## 先に知っておくこと

- **国の規約は「公共データ利用規約（第1.0版）」（PDL1.0）に移っている。** 令和6年7月5日にデジタル庁が定めた。
  - できること：複製・公衆送信・翻案（翻訳・変形など）。商用も可。
  - 条件：出典を記載する。編集・加工したときは、そのこととした者を出典とは別に書く。
  - 適用外：ロゴ・キャラクター・第三者の権利がある部分。
  - CC BY 4.0 と互換性がある。
  - 出典 https://www.digital.go.jp/resources/open_data/public_data_license_v1.0
- **旧内閣府防災（bousai.go.jp）は 2026-11-02 から防災庁のサイトになった。**
  - 新サイトの「このサイトについて」には再利用の条件が書かれていない。リンク自由と「Copyright 2026 National Disaster Management Agency」の表記だけ。
  - したがって bousai.go.jp の資料は、いまは「要確認」として扱う。
- **日本の防災ライブラリとして決定版の「東京防災」は配れない。** 都の許諾制で、営利・有償頒布は不可。
  - 自分の端末で個人として使うだけなら、私的複製の範囲で入れられる。ただし配る追加パックには絶対に入れない。

## 推奨の構成

- **日本語追加パック「小」（約0.4GB）**：A の PDF・HTML 全部、medicine・wikibooks・wikivoyage の ZIM
- **日本語追加パック「中」（約2.2GB）**：「小」に wikipedia_ja_top_nopic を足す
- B の問い合わせが通ったものから順に足す。食品ストックガイドと防災庁の資料が入ると、備蓄と避難の層が厚くなる

## 資料より先に直すこと（技術）

1. **日本語の本文検索：対応済み（2026-11-18）。**
   - 原因：もとの索引（SQLite FTS5、`unicode61`）は、日本語の連続した文字列を1語として扱う。そのため「煮沸」では0件になっていた。
   - 対応：`engine/ja_search.py` が、同じ search.sqlite の中に `pages_ja` を作る。日本語の文を2文字ずつ区切った索引で、英語の `pages` には手を入れない。
   - 引く側：検索画面（`server.find`）、AI の検索（`assistant.hybrid`）、百科事典の検索（`library.zim_hits`）の3つ。
   - 既存の search.sqlite に足すときは `python -m engine.ja_search <search.sqlite>` を実行する。
2. **日本語 ZIM の検索：そのままで使える（2026-11-18 確認）。**
   - wikipedia_ja_medicine_nopic_2026-10.zim を実際にダウンロードして試した。SHA-256 は公式の値と一致。
   - 「止血」「熱中症」「心肺蘇生」「煮沸」のどれでも、本文検索が日本語で正しく効いた。
   - ただし ZIM の中にはライセンスのメタデータがない。そのため出典ページには、Wikipedia の CC BY-SA 4.0 を自分たちで書く。
   - 質問文をそのまま渡すと外れやすい（「水を煮沸する方法」は0件だった）。そこで単語に分けて渡し、見出しが単語と一致する記事を先頭に出すようにした。
   - 本家の pack-spec にある `packaging/pack_merge.py` は、このリポジトリに入っていない。追加パックを結合する道具も自前で用意する必要がある。
3. **画面の百科事典一覧が固定になっている。** `web/app.js` の `ZIMS` に日本語 ZIM を足す。
4. **出典ページに書くこと。**
   - PDL1.0 と CC BY 4.0 の出典表示。
   - 「文字の抽出・スクリプト除去を Lastbook 日本語版が行った」という加工の表示。
5. **追加パックを組み立てる道具を自前で書く。** 本家の資料の組み立て道具は公開されていないため。
